Erklärungen der Git-Befehle

git clone:
Lädt ein Repository von GitHub auf den eigenen Computer herunter. 
Bsp. git clone https://github.com/SinemZaman/my-first-repository.git

git status:
Zeigt den aktuellen Status des Repositorys an.
Man sieht, welche Dateien verändert wurden oder noch nicht von Git erfasst sind.
Bsp. git status

git add:
Fügt Dateien zur Staging Area hinzu. Dadurch werden sie für den nächsten Commit vorgemerkt.
Bsp. git add index.html

git commit:
Speichert die vorgemerkten Änderungen im lokalen Repository mit einer Nachricht.
Bsp. git commit -m "Add personal HTML page"

git log:
Zeigt die bisherigen Commits und den Verlauf der Änderungen im Repository an.
Bsp. git log

git push:
Lädt die lokalen Commits auf das Online-Repository bei GitHub hoch.
Bsp. git push

git pull:
Lädt die neuesten Änderungen vom Online-Repository herunter und übernimmt sie in das lokale Repository.
Bsp. git pull
